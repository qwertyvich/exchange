# Разбор ветки palma_exchange

## Исправленные причины

| Было | Стало |
|---|---|
| SQLite по относительному пути; в production смонтирована другая папка, из-за чего БД могла оставаться в контейнере | PostgreSQL 17 в отдельном томе, healthcheck, Alembic, перенос прежних данных |
| Настройки JSON в памяти каждого процесса, часть параметров бота читалась один раз при импорте | Настройки в PostgreSQL; сохранение видно всем воркерам; бот читает актуальную конфигурацию |
| Каждая шапка/страница начинала с режима 0 и запрашивала настройки отдельно | Общая загрузка настроек до создания компонентов; показывается только выбранный режим |
| Общая заставка исчезала через секунду независимо от сети | Заставка связана с готовностью данных, есть обработка ошибки и повтор |
| Каждый браузер обращался к CoinGecko каждые 30 секунд | Серверный пакетный запрос, общий постоянный кэш и backoff; браузер обращается только к своему API |
| Клиентские суммы и комиссия принимались без независимой проверки | Подписанный 60-секундный расчёт, серверные лимиты, Decimal и NUMERIC |
| Невидимый слой списка валют перехватывал всю страницу | Внешняя область пропускает события; закрытие по нажатию вне списка и Escape, прокрутка работает |
| В мобильной панели click.self не срабатывал из-за отдельного фонового div | Закрытие по клику на фон; клики в самой панели работают как прежде |
| Отзывы каждый раз читались из JSON и загружались при переходе | 225 отзывов в PostgreSQL, HTTP-кэш и предварительная загрузка; повторные переходы используют уже загруженные данные |
| Пропущенная запасная картинка; изображения могли получать HTML при отсутствующем пути в nginx | Добавлен placeholder, проверены изображения в трёх режимах, статические файлы возвращают 404 при отсутствии, добавлены gzip и кэширование |
| Общий большой JS-файл для всех страниц | Отдельные чанки маршрутов |
| Админка с техническими названиями полей | Разделы с человеческими подписями, пояснение единиц курса, предпросмотр, ошибки валидации и подтверждение сохранения |
| Telegram вызывался в запросе и часть сбоев блокировала действия клиента | Постоянная очередь уведомлений, фоновые попытки; чек хранится в отдельном томе |
| Заявку можно было читать и менять по одному ID | Проверяется пользователь/гостевая cookie либо подписанная ссылка оператора |
| У вошедшего пользователя заявка создавалась, но затем открывалась с 404 | Загрузка, подтверждение и отмена отправляют токен владельца; загрузка чека сохраняет multipart boundary |
| Ошибка получения расчёта терялась из-за необъявленной переменной в catch | Причина показывается в форме, кнопку можно нажать повторно |
| Стекло списка валют менялось рывком при открытии | Убрана анимация прозрачности родителя, размытие и слой самой панели сохраняются на всём переходе |
| JWT/HMAC секреты и токен бота в коде | Случайные локальные секреты в игнорируемом `.env`, токен удалён из начального шаблона |

Внешний вид клиентских форм и три режима сохранены. Менялись загрузка данных, расчёты и поведение выпадающих элементов; отдельно обновлена админская форма.

## Проверено

- Перенос 13 пользователей и 136 заявок; 225 отзывов. Добавлен один локальный администратор.
- 11 backend-тестов: автоматический курс и комиссия, ручной приоритет, обратное направление, три режима, старые курсы, рублёвые тарифы, округление, устаревшие данные, валидация настроек, подмена суммы/направления, доступ к чужой заявке, повторная отправка одного расчёта и действия владельца с токеном.
- 30 браузерных сценариев: каждый режим с намеренно медленным ответом настроек; изображения и расчёт формы; выбор валют мышью и касанием; независимая прокрутка; открытие/закрытие стеклянных панелей и reduced motion; RU/EN и сохранение языка; админка; отзывы и стабильная пагинация на ширинах 320/390/932/1440 px; реальные локальные заявки гостя и пользователя с перезагрузкой, отменой и подтверждением с чеком; ошибка расчёта и постоянное размытие во время анимации; появление главной после исчезновения заставки; единые мобильные шапки Casper; цикл призрака, неподвижные аксессуары, пауза в меню и статичная версия при reduced motion. Созданные проверкой заявки удаляются по уникальной тестовой метке.
- HTTP-проверки сайта, API и проксирования. Сборка Vite.
- Обновлены совместимые зависимости frontend: npm audit больше не сообщает известных уязвимостей. Сборка переведена на Node 22.

Это локальное развёртывание. Настоящая доставка в Telegram намеренно не тестировалась; она выключена в `.env`. Обмены и выплаты по-прежнему исполняет оператор. Перед публичным запуском требуется настроить реальный домен/TLS, актуальные коммерческие курсы, заменить ранее опубликованный токен бота и перенести резервную копию базы.

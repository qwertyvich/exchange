# RU / EN

Язык переключается в общем компоненте `frontend/src/components/LanguageMenu.vue`, который используется во всех шапках, включая раскрытую мобильную панель.

- Выбор хранится в `localStorage` под ключом `palma.locale` (`ru` или `en`).
- По умолчанию используется русский. Сохранённый язык применяется до первого отображения страницы.
- Переключение не перезагружает приложение и не сбрасывает введённые суммы.
- Меняются подписи, формы и ошибки, FAQ, инструкция, правила, личный кабинет и админка; обновляются атрибут `lang`, заголовок вкладки и формат дат.
- Пользовательские имена, тексты отзывов и введённые реквизиты сохраняют исходный текст. Банковские логотипы и изображения инструкций остаются оригинальными.

Английские переводы находятся в `frontend/src/locales/en.json`. Ключ — исходная русская фраза. В шаблонах и вычисляемых подписях используется `tr(...)` из `frontend/src/lib/i18n.js`. Значения суммы передаются параметрами, например:

```js
tr('Минимум для внесения: {p0} {p1}', { p0: amount, p1: symbol })
```

Новые подписи нужно добавлять в словарь вместе с соответствующим вызовом `tr`. Содержимое отзывов и имена клиентов переводить не следует.

Языковое меню имеет ширину своей исходной кнопки; высота каждого варианта равна высоте кнопки. Список валют использует нативную прокрутку, явно принимает события указателя и ограничивает передачу прокрутки за свои границы через `overscroll-behavior`.

Проверки запускаются через `cd frontend && npm run test:e2e`. Они проверяют три режима, колесо внутри списка валют и вне него, границу списка, языковое меню при ширине 390/1280/1440 px, сохранение языка, сохранение сумм и переключатель в мобильной панели.

Также проверяются сам выбор валюты мышью и касанием, быстрый клик во время появления списка и устойчивость пагинации отзывов при смене страниц на ширинах 320/390/932/1440 px. Для запуска в WebKit (движке Safari): `npx playwright install webkit`, затем `PLAYWRIGHT_BROWSER=webkit npm run test:e2e`.
